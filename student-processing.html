Cloudflare

Cloudflare, Inc.의 호스팅·Workers·Durable Objects·일부 D1을 이용합니다. 요청 시 네트워크를 통해 접속 정보와 해당 앱의 방·응답·게임 상태 등이 처리됩니다. DPA는 일반 서비스 계약의 일부입니다. 개발 플랫폼 재수탁자 목록에는 Google·Oracle 및 처리 지역이 안내되어 있으나, 그 목록만으로 특정 래비토리 요청의 실제 국가를 확정할 수는 없습니다. 국내 한정 저장을 보장하지 않습니다. 개인정보 문의: privacyquestions@cloudflare.com. 앱 활성 기록은 앱별 별표의 만료 조건으로 삭제합니다. SQLite Durable Objects의 시점 복구는 과거 30일이며, D1 복구도 서비스의 Time Travel 정책을 따릅니다. 2026-10-25 관리자 화면에서 기존 Workers Paid 요금제를 확인했습니다. 현행 공개 정책에 따라 Workers Logs 보유기간은 7일입니다. 이번 작업에서 요금제를 변경하거나 새 유료 상품을 신청하지 않았습니다. 이 기간을 모든 Cloudflare 보안 로그의 기간으로 확대 해석하지 않습니다. DPA · 재수탁자 · Workers Logs · DO 복구 · D1 복구

Supabase

극저온 공유 자료의 DB·사진은 일본 도쿄, 냉각 곡선 공유 자료는 서울 프로젝트를 사용합니다. 일반 계약의 주 처리자는 Supabase Pte. Ltd.(싱가포르)이고 미국 계열사는 필요한 지원·운영을 수행할 수 있습니다. DB 지역과 지원·로그·CDN 처리 지역은 다릅니다. 공식 안내상 로그는 EU 데이터센터에서 처리되며 지원 인력은 글로벌입니다. 문의: privacy@supabase.io. 활성 공유 기록은 극저온 30일, 냉각 곡선 7일 조건으로 정리합니다. 무료 요금제의 공개 API/DB 로그 보유기간은 1일이며 사용자용 자동 백업은 포함되지 않습니다. 이것이 제공자 내부 사본의 부재를 뜻하지는 않습니다. 프로젝트 삭제 후 고객 데이터 삭제는 공식 안내상 30일 이내이며 개별 기록 삭제와 같은 절차가 아닙니다. 데이터 위치·삭제 안내 · 요금제별 로그·백업 · DPA

Google Firebase와 정기 삭제 도구

과학 퀴즈는 Firebase Authentication과 Firestore를 이용합니다. 인증은 미국에서 처리되며, 익명 식별자·최근 이용 시각 등이 계정 정리에 사용됩니다. 인증 IP 로그는 수 주, 계정 삭제 요청 후 활성·백업 시스템의 인증 데이터 제거는 최대 180일로 안내되어 있습니다. 앱의 1년 미사용 익명계정 삭제 예약과 제공자의 후속 삭제 기간을 구분합니다. Firestore·Authentication은 현행 Firebase 서비스 표에서 Google Cloud 약관 및 데이터 처리 부속계약 적용 대상으로 분류됩니다. 무료 정리 도구의 실행 환경인 Apps Script에는 별도 추가 약관과 Google APIs 약관이 적용됩니다. 정리 도구는 읽은 학생 내용을 보고서에 기록하지 않고 대상·성공·실패 건수만 남깁니다. 인증의 처리 위치·기간 · 서비스별 약관 · Cloud DPA · Apps Script 약관

페이지 로딩에 따른 외부 요청

26개 앱의 현재 공개 HTML에서 Cloudflare Web Analytics 스크립트가 확인됐습니다. 공식 FAQ는 원본 비콘을 7일 보유하고 이후 약 10%로 집계한다고 설명합니다. 쿼리 문자열을 기록하지 않는 분석 기능과, 호스팅·서버 보안 로그는 구분합니다. 호르몬 앱 등은 Google Fonts, 자기장 앱은 jsDelivr의 Three.js 파일을 불러옵니다. 이러한 파일 요청에도 접속 IP 등 네트워크 정보가 전달될 수 있어 “외부 전송 전혀 없음”이라고 표시하지 않습니다. 센서값·학습 답안을 이 업체에 업로드하는 기능과는 다릅니다. 분석 FAQ · Google Fonts 안내 · jsDelivr 정책
